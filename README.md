# mp4trim

**Minimal MP4 trimmer with playback and a drag-handle timeline.**

<br clear="left">

Built for hybrid DV/HDR10 files: playback runs on QtMultimedia
(hardware decode + audio), and if the system decoder chokes on a file
the app automatically falls back to ffmpeg-decoded frame previews (no
green/purple tint). Trimming is a pure stream copy, so Dolby Vision
metadata and all tracks survive untouched.

## Usage

Drag the **green** handle inward from the start and the **red** handle
inward from the end, then hit **Trim**. Output lands next to the source
as `name_trim_START-END.mp4`.

| Key | Action |
| --- | --- |
| `Space` | play / pause |
| `Left` / `Right` | step 1 s (`Shift` = 10 s) |
| `Enter` | trim |
| `Ctrl+O` | open (drag & drop also works) |

```
python mp4trim.py [file.mp4]
```

## Requirements

- Python 3.11+ with PySide6 + PySide6-Addons (QtMultimedia)
- ffmpeg / ffprobe on PATH (not bundled)

## Notes

- Default trim is stream copy: instant, lossless, but cuts snap to the
  keyframe at/before the in-point (a few seconds of slop possible).
- **Options → Frame-accurate** re-encodes video with x264 CRF 18 —
  exact cuts, but drops Dolby Vision metadata.
- **Options → Force ffmpeg preview** disables live playback and scrubs
  ffmpeg-decoded frames instead — use it if a file plays with wrong
  colors (DV profile 5 etc.).

## Build MSI

```
python -m pip install cx_Freeze
python setup.py bdist_msi
```

Installer appears in `dist/`. Installs per-user (no admin) with a Start
Menu shortcut; upgrades replace the previous version in place.
`icon.ico` is generated by `make_icon.py` (Pillow).
